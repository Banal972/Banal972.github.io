이번에 Manning에서 나온 <Hugging Face in Action>(Wei-Meng Lee)을 길벗출판사에서 번역해 출간해서 읽어보게 되었습니다.

해외에서 먼저 나온 책이라 번역본은 어떨지도 궁금했구요.

허깅페이스는 이미 몇 번 써본 적이 있습니다. 허브에 올라온 이미지 모델을 받아서 로컬에서 돌려보기도 했구요.

그런데 돌아보니 딱 거기까지였습니다. **모델을 가져와서 실행해본 것**이지, 트랜스포머 라이브러리로 직접 다뤄보거나 랭체인으로 애플리케이션을 엮어본 적은 없었습니다.

"모델을 쓰는 것"에서 한 발 더 들어가서 그 위에 뭔가를 직접 만들어보고 싶었고, 그래서 이 책을 펼쳐봤습니다.

## 어떤 책인가요?

한 줄로 정리하면 **허깅페이스를 중심으로 AI 애플리케이션을 직접 만들어보는 실습서**입니다.

표지의 부제처럼 트랜스포머, 에이전트, RAG까지 요즘 AI 개발에서 빠지지 않는 키워드를 한 권에 담고 있습니다.

목차 흐름을 보면 크게 세 단계로 나뉘는 느낌입니다.

1. **기초 다지기** : 트랜스포머 라이브러리, 그라디오, 멘탈 모델 이해
2. **모델 다루기** : 파이프라인으로 NLP 업무 처리, 데이터셋 탐색과 토큰화, 파인 튜닝과 멀티모달 모델
3. **애플리케이션 만들기** : 랭체인과 라마인덱스, 랭플로우, 에이전트 프로그래밍, 그라디오 웹 UI, GPT4All로 로컬 LLM 실행, 로컬 데이터 쿼리

여기에 MCP 서버 구축, 챗봇 UI, 스몰에이전트 같은 최신 주제까지 다루고 있어서, 모델을 "불러다 쓰는 것"에서 끝나지 않고 실제로 돌아가는 서비스 형태까지 가보는 구성입니다.

## 읽어본 소감

가장 좋았던 점은 **"모델을 받아서 돌려보는 것" 다음 단계를 채워준다는 점**이었습니다.

예전에는 모델을 받아서 실행하면 끝이었는데, 이 책은 트랜스포머 라이브러리와 파이프라인으로 모델을 직접 다루고, 데이터셋과 토큰화를 거쳐 파인 튜닝까지 이어집니다. 그동안 블랙박스처럼 쓰던 부분이 어떻게 돌아가는지 감이 잡히는 느낌이었어요.

그다음 랭체인, 라마인덱스, 에이전트로 넘어가면서 모델 하나를 실행하는 게 아니라 여러 도구를 엮어서 하나의 애플리케이션으로 만드는 과정을 보여주는데, 제가 딱 궁금했던 부분이었습니다.

특히 그라디오로 UI를 붙이는 부분이 반가웠는데요, 프론트엔드 개발자 입장에서는 모델을 돌려보는 것보다 결과를 화면에 보여주는 게 훨씬 익숙하다 보니 "아 이렇게 빠르게 데모를 만들 수 있구나" 싶었습니다.

로컬에서 모델을 돌려본 경험이 있다 보니 GPT4All로 로컬 LLM을 실행하고 내 데이터를 쿼리하는 챕터도 반가웠습니다. 이미지 모델을 돌리던 것에서 한 단계 나아가 로컬 LLM으로 실제 쓸모 있는 기능을 만들어볼 수 있겠다는 생각이 들었어요.

다만 범위가 넓은 만큼 **한 주제를 아주 깊게 파는 책은 아닙니다.** 랭체인이나 에이전트를 본격적으로 쓰려면 공식 문서나 다른 자료를 같이 보는 게 좋을 것 같아요. 또 이 분야는 라이브러리 버전이 정말 빠르게 바뀌다 보니, 예제를 따라 할 때 버전 차이로 막히는 부분이 생길 수 있다는 점도 염두에 두면 좋겠습니다.

## 이런 분들께 추천드립니다

1. 허깅페이스에서 **모델을 받아 써보긴 했지만 그다음 단계가 막막한 분**
2. 모델을 실행하는 것을 넘어 **AI를 활용한 서비스를 직접 만들어보고 싶은 개발자**
3. 트랜스포머, 랭체인, RAG, 에이전트, MCP 같은 키워드를 **흐름 있게 한 번에 익히고 싶은 분**

저처럼 "써보긴 했는데 제대로 안다고 하긴 애매한" 상태라면 한 단계 더 깊이 들어가기에 좋은 책입니다.

저도 시간 날 때마다 예제를 하나씩 직접 돌려보면서 사이드 프로젝트에 적용해봐야겠습니다:)
